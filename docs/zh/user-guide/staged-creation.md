# 分阶段创作与视频风格

默认创作流程为：

`创意简报 → 风格选择 → 文案确认 → 分镜确认 → 生成视频`

规划阶段不会生成媒体。最后一步会展示推荐生成设置；如果分镜尚未确认，会直接提供“去
确认分镜”按钮。确认设置后，系统自动检查精确的“风格/模板/工作流/运行环境”组合并
准备生成，不再要求 Canary 或人工批准。

## 项目修订

项目保存在 `data/projects/<project_id>/`。每次写入都必须携带 `expected_revision`；陈旧
写入返回 HTTP 409，不会覆盖较新的编辑。锁定会生成内容哈希。生产只消费已锁定的旁白
和视觉提示词，不会重新调用规划模型改写内容。

编辑单个分镜只会把该分镜的媒体标记为失效。再次生产时会复用其他未变化分镜的片段，
并按当前顺序重新拼接成片。

## 风格

`StyleProfile` 同时约束文案语气、节奏、视觉与负向提示词、色彩、光线、构图、材质、
人物一致性、运镜、转场、模板、工作流、配音、语速和 BGM。系统预设不可变；高级设置
覆盖会创建项目自己的派生风格。

自定义风格可由自然语言结构化。三张代表性预览图只有在用户明确点击后才生成，因为会
消耗服务商额度或 GPU 资源。

## 素材

浏览器上传默认上限为每文件 512 MB。本地导入默认拒绝，只有绝对父目录出现在
`assets.allowed_import_roots` 时才允许。格式由 Pillow 和 FFprobe 的真实解码结果判断，
不信任扩展名。系统保留原件与 SHA-256，只把缩略图和 H.264 代理文件作为派生文件保存。

每个分镜都能通过稳定的素材 ID 引用项目素材。锁定前可预览 `cover`/`contain` 及水平、
垂直焦点；生产时按该配置创建可追踪的画布派生文件，不会裁切、重编码或覆盖不可变原件。

## 自动运行检查

运行检查绑定风格版本与哈希、模板哈希、工作流哈希，以及相关运行时节点和模型合同。
任一合同变化都会产生新的组合哈希，并在锁定前重新检查。

普通创作会自动检查模板、工作流、ComfyUI 节点和模型是否齐全，不需要单独执行 Canary
或人工批准。画布、模板、工作流、配音、语速和 BGM 默认使用风格推荐值；只有需要覆盖
时才展开高级生成设置。

运维人员仍可单独启动 **Compatibility** 诊断页，执行只读工作流审计并查看历史记录；它
不出现在普通创作导航中。普通生成绝不安装模型/节点或重启 ComfyUI；远程修复需要单独
的管理通道。
